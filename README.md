# TaskFlow

> A full-stack Task & Project Management application built as a portfolio project.

## Stack

| Layer | Technology |
|-------|-----------|
| Backend | PHP 8.4 · Symfony 8.0 · API Platform 4.3 |
| Database | PostgreSQL 17 · Doctrine ORM |
| Auth | JWT (LexikJWTAuthenticationBundle) |
| Frontend | Next.js 16.2 · TypeScript · React · Tailwind CSS |
| Infra | Docker · Docker Compose |

## Architecture

The backend follows **DDD / Clean Architecture**:

```
backend/src/
  Domain/         # Entities, Value Objects, Repository interfaces, Domain Events
  Application/    # Use cases / Command & Query handlers (no framework deps)
  Infrastructure/ # Doctrine repos, external services
  Api/            # API Platform Resources (DTOs, State Processors/Providers)
```

## Quick Start

```bash
docker compose up -d
# API available at http://localhost:8080/api
# Frontend at http://localhost:3000
```

## Features

- 🔐 JWT Authentication (register / login / refresh)
- 📁 Projects with members & roles
- ✅ Tasks with state machine (todo → in_progress → review → done)
- 💬 Comments on tasks
- 🖥️ SSR dashboard with Next.js Server Components
- 🧪 PHPUnit test suite (domain + API functional tests)
